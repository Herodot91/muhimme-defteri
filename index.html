Metode digitale în prelucrarea materialelor arhivistice otomane publicate

Demonstrație statică a interfeței aplicației, rezultat al comunicării științifice „Metode digitale în prelucrarea materialelor arhivistice otomane publicate: cazul Mühimme Defterleri”.

Această pagină rulează integral în browser, fără niciun server — de aceea arată doar corpusul demonstrativ fictiv (cele 12 înregistrări marcate „Exemplu demonstrativ” de mai jos), pentru a ilustra mecanismele aplicației (filtre, cronologie, teme, documente). Extragerea reală din PDF-uri (Eflak / Boğdan / Erdel, hükümuri, rețele, hartă istorică) necesită un backend Python și nu poate rula static pe GitHub Pages.
